EpicSeven Clock Bot

Never miss an Epic Seven reset. One live message in your server counts down to the daily reset, the weekly reset and the next Guild War phase, and pings your role when it matters.

Add to Discord How to set it up

Free on every server. Every feature and command, no premium.

What it does

Everything updates live every 5 seconds, so the countdowns are always right.

  • 🕒Live embedServer time, Daily Reset, Weekly Reset and the Guild War phase with its countdown.
  • #️⃣Channel name timersThe category name updates every 10 minutes with compact reset times.
  • ⚔️Guild War pingsAutomatic role pings when war starts, at 12 hours left and at 2 hours left.
  • ⏳Countdown timersAs many named timers as you like, each with its own ping when it runs out.
  • 🗓️Custom pingsDaily or weekly scheduled role pings with your own message.
  • ♻️Auto-repostIf the embed gets deleted, the bot posts it again.

Set up in four steps

Add the bot, then run /setup. You need the Manage Server permission.

  1. RegionPick your server's Epic Seven region. For Europe you'll also give a UTC offset.
  2. CategoryPick the category the bot will rename with live timer info.
  3. Embed channelPick the text channel where the live embed is posted.
  4. RolePick the role the bot pings for all notifications.

After you confirm, the bot posts the live embed and starts tracking straight away.

Running /setup again on a server that's already set up shows a warning first, because it resets all data.

Commands

All commands are free.

General

CommandWhat it does
/setupRun the 4-step setup (needs Manage Server)
/dailyShow the next Daily Reset countdown
/weeklyShow the next Weekly Reset countdown
/guildwarShow the current Guild War phase and countdown
/helpShow all commands

Settings

CommandWhat it does
/settings look_newNew-style embed (separator lines, lowercase units)
/settings look_oldClassic embed layout (default)
/settings dash_onDashes in countdown strings
/settings dash_offNo dashes in countdown strings (default)

Countdown timers

CommandWhat it does
/countdowntimer createMake a named timer with a ping when it ends
/countdowntimer checkList all active timers
/countdowntimer clear <number>Remove a timer by number
/countdowntimer hideHide timers from the embed
/countdowntimer showShow timers in the embed

Give it a title (e.g. Moonlight Covenant Event), a duration in days, hours and minutes, and the message to send when it runs out.

Custom pings

CommandWhat it does
/customping createMake a daily or weekly ping
/customping listSee all pings and their numbers
/customping delete <number>Delete a ping by number

Choose daily or weekly (and the day), a time in UTC (HH:MM), your message, and who to ping: the default role, another role, or one person.

Guild War

Guild War runs on a fixed UTC schedule in every region. Each war lasts 24 hours from 03:00 UTC. /guildwar and the embed always show the current phase and a countdown to the next one.
