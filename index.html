MLST Typing

Automatic MLST of genome assemblies

Give it one or more assembled genomes and it finds the PubMLST scheme that fits best, then reports the sequence type (ST) and the allele of every locus, cross-checked with EnteroBase. You do not need to know the species first.

  • 162 schemes from PubMLST and BIGSdb-Pasteur
  • Also checks the EnteroBase schemes (Escherichia, Salmonella, Yersinia, Moraxella), which hold newer STs; their ST is shown when PubMLST has none, with a warning saying so
  • Python and BLAST+ only; reads FASTA, GenBank and EMBL, plain or compressed
  • Same results as mlst on its test genomes and one public genome per scheme
  • Tied schemes are listed, not picked at random, and a new MULTICOPY status for loci with several identical copies
GitHub Galaxy Tool Shed Commandless

Genomics Workflow Microbials

Desktop app for bacterial isolate typing

Built for bioinformaticians, laboratories and researchers, and for anyone who wants an easy-to-use tool. It types bacterial isolates from paired Illumina reads, or your own FASTQ reads, on your own computer. It supports your whole genome sequencing work without the burden of the command line. No server is needed: it all runs locally on your computer. It lets you import workflows from Galaxy Australia, and gives you an easy way to install any bioinformatics tool from GitHub, so you can bring the tools your work needs.

Have an issue or a problem? I am here to help. I give support and can make the app work with other tools: open an issue.

  • One installer for Windows, Mac and Linux: no Nextflow, Java or Python to set up
  • Every tool in its own container at a fixed version, so results are repeatable
  • Every run in one folder, with its results and a record of exactly what ran
  • Workflow builder, Import from Galaxy (.ga), and tools added from their GitHub link
  • Stopped or failed runs carry on from where they were
GitHub Download Privacy policy

Built for Galaxy Australia, and they run on the command line too. ShigaPass typing is redesigned from ShigaPass, Mykrobe and mykrobeshig; MLST Typing is redesigned from Torsten Seemann's mlst.
